| 项 | 内容 |
| --- | --- |
| 平台 | 抖音 / 小红书 / 视频号，竖屏 9:16，1080×1920 |
| 时长 | 主版本 62 秒；精简版 20 秒（见第 4 节） |
| 目标观众 | 参加黑客松、创业营的开发者，已经在用 Claude Code 之类的编程 Agent |
| 一句话卖点 | **一行指令丢给你自己的 Agent，它采访你、给你写一页独一无二的组队页，挂到活动的墙上。** |

---

## 1. 爆款逻辑（剪辑时照着取舍）

1. **先给结果，再讲过程。** 第 1 秒就出现一张会动、很酷的页面，不从 logo 或问题开始。
2. **只讲一个痛点。** 黑客松群里一百条“大家好，我叫 XX，全栈，求组队”，谁也记不住。
3. **反差点是“不是模板”。** 两张风格完全不同的页面并排出现，比任何解释都有说服力。
4. **开发者会截图的爽点是“Agent 自己截图检查、自己改”。** 这一段要给特写，不能一闪而过。
5. **结尾接回开头。** 最后一帧和第一帧是同一张页面，循环播放时看不出接缝，能拉高完播率。

## 2. 主版本分镜（62 秒，按开头 A 写）

> 口播约 310 字，语速偏快（每秒约 5 字），整条几乎不留空白，像创始人一口气跟朋友安利。字幕每屏不超过 12 个字，关键词高亮成荧光绿或信号橙，和两张示例页的主色一致。
>
> 带 ⚠ 的台词写的是“我”的亲身经历。如果和你的真实经历不符，按你自己的经历改，不要照念。

### 镜 1 · 0:00–0:05 · 结果先行

- **画面**：录屏。R3 这次真实生成的林舟页面在手机框里全屏播放（下面按“终端风”描述，以实际生成结果为准）：等宽字逐行打出，荧光绿招募卡弹出。镜头从页面局部慢慢拉远，露出整页。
- **字幕**：这不是模板
- **口播**：这不是模板。这一整页，是 Agent 采访完一个人以后，从零写出来的。
- **音效**：键盘声 + BGM 鼓点在 0:01 进
- **素材**：录屏 R1

### 镜 2 · 0:05–0:12 · 痛点

- **画面**：AI 生成。一个“黑客松交流群”的聊天界面，几十条长得一样的自我介绍飞速上滑，最后糊成一片灰色。头像用色块或抽象图形，不出现真实人脸和真实 App 界面。
- **字幕**：100 条自我介绍 / 一条都记不住
- **口播**：⚠ 每次参加黑客松，一进群就是一百条“大家好，我叫某某，全栈，求组队”。刷完一遍，我一个都没记住。
- **音效**：消息提示音叠加、越来越密，最后“噗”一声静音
- **素材**：AI 画面 G1

### 镜 3 · 0:12–0:16 · 转折：扫码、复制一行

- **画面**：录屏。手机框里扫活动二维码 → 墙首页 → 工作区“Agent 指令”卡片 → 手指点「复制指令」。指令里的 token 打码。
- **字幕**：所以我做了 NOWMe
- **口播**：所以我做了 NOWMe。扫码进活动的墙，复制一行指令，
- **音效**：“咔哒”复制音
- **素材**：录屏 R2

### 镜 4 · 0:16–0:23 · Agent 采访

- **画面**：录屏。Claude Code 终端（深色、字号放大）粘贴指令 → Agent 开始提问，带选项：“你最拿手的是？”“这次想找什么样的队友？”“想做个什么？”。回答一闪而过，选项被逐个选中。
- **字幕**：它先采访你 / 不用填表
- **口播**：丢给你自己的 Agent，比如 Claude Code。它不让你填表，先采访你：最拿手什么，想找谁，想做什么。
- **音效**：轻快的打字声
- **素材**：录屏 R3

### 镜 4b · 0:23–0:28 · 改一句再确认

- **画面**：录屏。Agent 输出一段“我眼中的你”，其中一句被高亮划掉 → 打字改成“其实我前端也能写一点，但不想被当成前端” → 回复“确认”。
- **字幕**：哪句不对，你来改
- **口播**：问完它先说一段“我眼中的你”，哪句不对你就改，你确认了它才动手。
- **音效**：划掉时“唰”一声
- **素材**：录屏 R3（同一次运行）

### 镜 5 · 0:28–0:36 · 自己写、自己截图、自己改（技术爽点）

- **画面**：录屏加速 8–16 倍。终端里文件一个个写出（`index.html`、`card.json`…）→ 出现一张页面截图缩略图 → Agent 说“标题和招募卡挤在一起了，我改一下” → 再截一张，变好了 → 绿色“通过校验”。最后 1 秒定格在“通过校验”。
- **字幕**：自己写 → 自己截图检查 → 改到满意
- **口播**：然后全是它自己干：写页面、截图，发现标题挤了就自己改，改完再截一张，过了校验才交上来。
- **音效**：快进的“唰唰”声，定格时“叮”
- **素材**：录屏 R3（同一次运行）。台词里的“标题挤了”按实际录到的问题改

### 镜 6 · 0:36–0:44 · 反差：每个人都不一样

- **画面**：录屏。左右分屏或快切：
  - 左：林舟的终端风页面，命令行区块在跑
  - 右：苏晴的瑞士海报风页面，点一下匹配小测，再撕下一张撕条
  - 最后 1 秒两张页面并排缩小，周围飞入更多卡片
- **字幕**：有人是一段程序 / 有人是一张组队海报
- **口播**：所以每一页都不一样：有人是一段正在跑的程序，有人是一张贴在走廊里的组队海报，撕条还真能撕。
- **音效**：BGM 进副歌
- **素材**：录屏 R1、R4。林舟页的描述按 R3 实际生成的风格改

### 镜 7 · 0:44–0:54 · 上墙、找人、直接聊

- **画面**：录屏，分三拍：
  1. **0:44–0:47 找人**：墙首页一屏缩略卡，手指下滑 → 点开苏晴 → 停在接话点“找一位后端，最好也懂 AI” → 点「想聊这个」。
  2. **0:47–0:51 私聊**：直接跳进站内私聊，输入框里已经填好开场白“苏晴你好！我写后端，也调过大模型 API，看到你的组队启事想来聊聊～”，下方提示“已带入话题开场白，可以修改后发送”→ 点「发送」→ 2–3 秒后苏晴的回复弹出：“来！今晚 8 点线上过一下点子？”（加速到 1 秒内）。
  3. **0:51–0:54 群聊**：返回墙首页，点「全员群聊」→ 群里消息正在往上滚，大家在约队、约饭，消息里能看到真实的成员昵称。
- **字幕**：「想聊这个」→ 开场白已填好 / 不用加微信，直接聊 / 墙里还有全员群
- **口播**：大家挂在同一面墙上。看到对的人，点“想聊这个”，开场白已经帮你填好，点发送就聊上了；墙里还有全员群，不用再拉微信群。
- **音效**：发送时“咻”一声，回复弹出时“叮”
- **素材**：录屏 R5

### 镜 8 · 0:54–1:02 · 行动号召，并接回开头

- **画面**：NOWMe 字标居中 0.5 秒 → 画面收缩成墙上的一张卡片 → 镜头推进这张卡片，正好是镜 1 的林舟页面（循环接缝）。
- **字幕**：评论区扣「上墙」/ 私信你内测链接
- **口播**：测试版已经上线了。评论区扣“上墙”，我私信你内测链接；你是活动方的话，我直接给你的活动开一面墙。
- **音效**：BGM 收在一个重拍上，接回镜 1 的键盘声
- **素材**：AE / 剪映模板 + 录屏 R1

## 4. 素材清单

### 4.1 录屏（真实产品，本地运行）

准备：`pnpm dev` 启动，`pnpm --filter @nowme/web seed` 灌入黑客松墙和示例成员。浏览器用 390×844 的移动端视口录，导出后放进统一的手机框模板。

| 编号 | 内容 | 注意 |
| --- | --- | --- |
| R1 | **R3 生成的林舟页**完整播放一遍动效 | 录 2 遍，一遍静止、一遍带手指交互。镜 1 说的是“你的 Agent 给你写的”，所以必须用 R3 的真实产物，不能拿 `skill/examples/hackathon-terminal` 顶替；效果不够好就重跑 R3。示例页只能当墙上的其他卡片 |
| R2 | 扫码 → 墙首页 → 工作区 →「复制指令」 | **指令里的 token 必须打码**，它等同于钥匙 |
| R3 | Claude Code 用虚拟人设林舟真实跑一次：采访 → 写文件 → 截图自查 → 修改 → 提交通过（人设和答案见 5.2） | 用一个新的测试账号，昵称填“林舟”；终端字号 ≥ 20pt，深色主题；全程录下来再挑段落；如果这一次没有出现“截图后发现问题并修改”，就多跑几次，挑一次有的用，不要伪造 |
| R4 | 苏晴页（`skill/examples/hackathon-poster`）：匹配小测、撕条 | 交互要点得慢一点，方便加速 |
| R5 | 用林舟的账号：墙首页滑动 → 苏晴 →「想聊这个」→ 私聊里发送预填的开场白 → 收到苏晴回复 → 返回墙 →「全员群聊」 | 需要两个浏览器：一个登录林舟、一个登录苏晴，林舟发出后切到苏晴那边发回复，页面每 2.5 秒刷新一次，回复会自己弹出来。全员群里提前用 4–6 个账号发十几条消息（约队、约饭、问场地），画面才显得热闹。墙上要先有 6–10 张卡片（seed 数据 + 示例页） |

所有录屏都要**隐藏地址栏**（现在是 `localhost` 和 `127.0.0.1`，会显得是半成品）。用浏览器全屏或无边框窗口录。

### 4.2 R3 虚拟人设：林舟

林舟和苏晴都是虚构人物：画面里不出现真实的学校、姓名或照片，视频简介里加一句“演示人设为虚构”。

照着下面的答案回答 Agent，录出来的内容才能和镜 4、镜 4b、镜 7 对上。答案可以复制，但最好手打一遍，画面里有真实的打字过程。

| 项 | 设定 |
| --- | --- |
| 昵称 | 林舟 |
| 身份 | 大三，计算机专业 |
| 角色 | 开发，全栈偏后端 |
| 做过的东西 | “书递”：校内二手书流转的微信小程序，我写了后端接口和数据库，上线一学期，三百多本书换了主人 |
| 想找的队友 | 会做视觉和交互的设计 |
| 这次想做 | 课程群通知自动变待办：群里的作业、调课通知自动整理成待办清单 |

**采访答案**（对应 Agent 的编号选择题，题号以实际出现的为准）：

- **素材**：`做过一个校内二手书小程序“书递”，我写的后端接口和数据库，上线一学期，三百多本书换了主人`
- **选择题**：`1a 2bc 3a 4ac 6a 7b 8 去掉 a b`
  - 角色：开发；技能：后端、全栈；队友：会做视觉 / UI 的设计；方向：AI 应用、校园 / 生活服务
  - 风格：深色终端控制台；动效：适中
  - 不显示学校和年级专业，不用真名，不放照片
- **追问**（如果问到想法）：`已经有明确的点子：课程群里的作业和调课通知太多，想让它们自动变成待办`
- **确认“我眼中的你”**：先挑一句不准的改掉（例如“其实我前端也能写一点，但不想被当成前端”），录下“改一句再确认”的过程，用在镜 4b

### 4.3 配音与音乐

- 配音：AI 年轻声线，语速偏快、口语化，像跟朋友安利，不要播音腔。
- BGM：发布前一周从平台热门音乐榜挑一首节奏明确的电子 / Lo-fi，**副歌对齐镜 6**。用平台曲库里的音乐，避免版权下架。
