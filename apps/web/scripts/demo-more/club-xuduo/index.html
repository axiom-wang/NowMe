02

可以来问我怎么选片和排版

  • 01选片

    先挑五张，再按情绪删到三张，留下的每张都要能一句话说清为什么。

  • 02排版

    先定一条主线，所有文字都靠它对齐，不靠感觉挪位置。

  • 03留白

    字太多就删字，别把图缩小去凑。

示意：一张主图、一个红色信息栏、一条标题线
