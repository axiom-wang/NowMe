# 演示墙第二批人物页（demo-more）

四面演示墙各把人数扩到两倍时新增的 34 位虚构人物，每个目录是一次提交的三个文件（`index.html`、`card.json`、`manifest.json`）。名单、邮箱与是否公开联系方式在 `../demo-more.ts`，种子按名单走真实提交管线（校验 + 渲染）挂上墙，`test/demo-more-content.test.ts` 守住契约。

页面由维护者按下面的设计方向逐页手写，不是模型生成的。改内容时保持人物事实、接话点与设计方向一致，并重新跑校验。

## 共同要求（每一页都要满足）

**只写自己的目录**：`apps/web/scripts/demo-more/<dir>/` 下恰好三个文件，不放 `cover.png`、`DESIGN.md`、草稿。

**契约**（`docs/contracts/01-page-output.md`）：
- `<!doctype html>`、`<html lang="zh-CN">`、`<meta charset="utf-8">`、`<meta name="viewport" content="width=device-width, initial-scale=1">`，`<link rel="stylesheet" href="/_nowme/kit/v1/nowme.css">`。
- 至少 4 个 `data-nm-id` 区块（小写字母开头，`a-z0-9-`），和 `manifest.blocks` 完全一致、顺序相同。区块名按这个人的内容起（例如 `departure-board`），不要一律 `hero/about/work`。
- 不引用任何外部资源；不写 `<a href>`（页内锚点除外）、`<form>`、`<iframe>`；图像只用内联 SVG 或 CSS 画，不用 `assets/`。
- 默认不写脚本。确实需要时只做无网络的小交互，动效检查 `matchMedia('(prefers-reduced-motion: reduce)')`。CSS 动效最多一两处、克制（Kit 已在减少动效时关闭）。
- 字体只用 Kit 清单，通过变量 `var(--nm-font-<id>)` 使用，并在 `manifest.fonts` 里声明用到的 id 与字重：
  中文 `lxgw-wenkai`(300/400/500)、`smiley-sans`(400)、`noto-sans-sc`(400/500/700/900)、`noto-serif-sc`(400/700/900)；
  西文 `inter`(400/500/700/900)、`space-grotesk`(300/400/500/700)、`jetbrains-mono`(400/500/700/800)、`instrument-serif`(400)。
  **中文字体的字重合计不超过 2 个**（例如 `noto-sans-sc` 400+900，或 `lxgw-wenkai` 400 + `smiley-sans` 400）。CSS 里出现的 `font-weight` 只用声明过的字重。
- `index.html` 小于 60 KB。

**内容**：
- 页面里出现人物名字、所在墙的名字（简称即可，如“山海摄影社”“NOWMe 演示黑客松”“AI 共创实验室”“山野轻徒步”），以及 `card.json` 里每个接话点的 `text` 原文。
- 不出现邮箱、微信号、手机号、网址、二维码；不冒充实拍照片（插画就标“示意”或“插画”）；不出现真实品牌、商标、产品名，不模仿任何现有游戏、应用或网站的界面。
- 结尾一句引导到页面外的按钮，例如“在页面外点「想聊这个」，从……开始。”——页面里不放按钮假装能联系。
- 文字具体、有个人口吻，像本人写的；中文排版，标点用全角。

**card.json**：`schemaVersion: 1`；`displayName` 与名单一致；`tagline` ≤ 40 字；2–3 个 `hooks`，`id` 小写短横线，`text` 2–32 字，`opener` ≤ 80 字、以对方名字称呼对方，`kind` 用墙的场景：
- 黑客松 / AI 共创（`hackathon`）：`can-help`（我能帮你做 X）、`looking-for`（找会 Y 的队友）、`want-to-build`（我想做 Z）。
- 摄影社 / 轻徒步（`club`）：`ask-me`（可以来问我 X）、`want-to-try`（我也想试 Y）、`obsessed`（我在沉迷 Z）。

**manifest.json**：`{"schemaVersion":1,"sceneType":"hackathon"|"club","kitVersion":"1","motionLevel":"calm"|"medium","fonts":[…],"extraChars":"","blocks":[…],"generator":{"agent":"nowme-demo"}}`。

**设计**：
- 页面里恰好一个 `<h1>`，内容是人物名字，并且在 375px 宽的首屏 500px 以内可见。
- 375px、390px、768px、960px 宽都不出现横向滚动、没有元素超出视口左右边界；≥ 700px 用一个媒体查询换成更舒展的版式。正文 ≥ 14px，对比度足够。
- 每一页的视觉隐喻都从这个人本身推出来（下面每人一条方向），整页的版式、DOM 结构、区块顺序都不一样，不要套“大标题 + 三张卡片”的通用模板。首屏（375×500）就要看出是谁、他的那个隐喻。
- 质量参照：`../demo-people/hack-chengye/index.html`、`../demo-ai/research-canvas.ts`。

**自查**：
1. `pnpm nowme validate apps/web/scripts/demo-more/<dir>` 必须是“通过，没有错误和警告”。
2. `rm -rf /tmp/nowme-more-preview/<dir> && mkdir -p /tmp/nowme-more-preview && cp -r apps/web/scripts/demo-more/<dir> /tmp/nowme-more-preview/` 后运行 `pnpm nowme preview /tmp/nowme-more-preview/<dir>`，用读图工具看 `/tmp/nowme-more-preview/<dir>/cover.png` 与 `.nowme-preview/` 下的整页截图：文字溢出、重叠、看不清、横向滚动、大片空白都要修完再交。
