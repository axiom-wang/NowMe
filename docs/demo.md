# NOWMe｜评委本地体验指南

华硕 A+ 青年 Create Lab 2026 · 团队 Axiom

[返回项目首页](../README.md)

NOWMe 帮助刚进入新圈子的年轻人，和 AI 一起制作一页有个性的自我介绍，并挂在圈子的共同墙上，让认识彼此、发现共同兴趣和寻找队友更自然。

本次提交为本地运行原型，支持测试身份一键登录，无需真实邮箱注册、密码或验证码。推荐先用约 3 分钟浏览已有内容，再预留 10–15 分钟体验完整 AI 创作流程；模型耗时可能更长。

## 1. 在哪里打开

如果提交者已在体验电脑上启动项目，直接打开 [体验首页](http://localhost:3000)，跳到第 3 节。

如果在自己的电脑体验，请先完成第 2 节。本项目未部署公开网站；`localhost` 指当前使用的电脑，不是可从其他电脑直接访问的在线演示地址。

## 2. 首次安装与启动

### 环境要求

- Git，用于下载项目。
- Node.js **22，至少 22.13.0**；仓库 `.nvmrc` 指定 22。
- pnpm **12.8.1**，与仓库 `packageManager` 一致。
- 可用的网络连接：安装依赖、下载 Chromium 与字体、调用 AI 模型均需要联网。
- 本地 **3000、4000** 端口可用，体验时只需打开 3000。

如已安装 Node.js，但没有 pnpm，可执行：

```bash
npm install --global pnpm@12.8.1
```

### 下载和运行

以下命令可在 macOS、Windows PowerShell 或 Linux 的终端中逐行执行：

```bash
git clone https://github.com/axiom-wang/NowMe.git
cd NowMe
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm demo
```

如已下载仓库，请直接进入包含 `package.json` 的项目根目录，从安装依赖开始执行。Linux 如果提示缺少浏览器系统依赖，请运行 `pnpm exec playwright install --with-deps chromium`，系统可能要求管理员权限。

Chromium 用于后台渲染、检查和截图人物页面，即使平时用其他浏览器，也需要安装。无需先执行 `pnpm build`。

首次启动会自动下载缺失字体，并初始化四面墙、人物页面和聊天数据，可能需要几分钟。看到以下提示后再打开页面：

```text
NOWMe 黑客松评审演示已就绪
```

打开 **[http://localhost:3000](http://localhost:3000)**。保持该终端运行，不需要再开一个终端启动页面服务。

仓库提供演示专用模型配置，评委无需提供自己的 API Key。终端出现“演示模型已配置”表示配置已载入，实际能否调用仍取决于服务商网络、权限和额度。若模型暂时不可用，可先体验已有内容，处理方法见第 7 节。

## 3. 测试身份与登录

首页或 [登录页](http://localhost:3000/login) 提供两个按钮，点击即可登录：

| 入口 | 推荐用途 | 可以体验什么 |
| --- | --- | --- |
| 以成员身份体验 | 首先体验 | 浏览四面墙、人物页面、群聊与私聊；在黑客松墙采访、生成、修改并发布自己的页面 |
| 以组织者身份体验 | 随后体验 | 进入黑客松墙的组织者后台，查看成员发布状态、管理成员与邀请 |

登录后先进入首页，再从墙卡片进入浏览、创作或管理功能。背景人物没有登录入口，无需尝试使用他们的邮箱登录。

切换时，打开顶部账号菜单，点击“切换身份”，然后选择另一个入口。退出时在同一菜单中点击“退出登录”。切换身份会替换当前会话；如果希望同时比较两个身份，可以分别使用普通窗口与无痕窗口。

## 4. 快速体验：约 3 分钟

| 步骤 | 操作 | 建议观察 |
| --- | --- | --- |
| 1 | 点击“以成员身份体验” | 无需注册即可进入已有圈子 |
| 2 | 浏览“NOWMe 演示黑客松”的人物墙，打开两三个成员页面 | 每个人的表达与视觉风格不同，可以发现技能、兴趣及交流话题 |
| 3 | 从“我的”返回首页，浏览摄影社、AI 共创或山野轻徒步等其他墙 | 不同圈子对应不同自我表达场景；不是所有成员都已发布页面 |
| 4 | 点击“消息”，打开群聊或私聊，可尝试发送一句测试消息 | 人物展示如何衔接进一步交流；消息保存在本机演示数据中，不会发送给真实人物 |
| 5 | 通过账号菜单切换为组织者，进入黑客松墙的“组织者后台” | 可查看成员与发布状态、管理邀请；不能查看其他成员的草稿和采访资料 |

为了方便继续体验，首次浏览组织者后台时可先查看列表与邀请入口；移除成员会实际影响当前演示数据及其页面展示。

## 5. 完整体验：从采访到发布

### ① 进入自己的创作工作区

使用成员身份登录，在“NOWMe 演示黑客松”墙卡片中点击“继续创作”。初始演示数据为该账号保留空白创作页，便于体验全过程。如果已经有版本，可以继续预览或修改。

### ② 开始采访

在“在这里创作”区域点击“开始采访”。填写自己的介绍，选择相应选项、页面风格和动效偏好，点击“下一步”，按页面提示回答 AI 的追问。

可使用下面这段虚构素材，无需填写真实隐私信息：

> 我叫阿柚，是数字媒体专业的大四学生，会一点 TypeScript 前端，也喜欢城市摄影。这次黑客松想做一个帮助新朋友寻找队友的小工具，希望认识一位设计师。我可以负责交互和原型，做过校园活动报名小程序，但没有公开作品链接，请不要编造。希望页面简洁，用深色和绿色，少一点动效，联系方式暂不公开。

### ③ 确认“AI 眼中的你”

查看 AI 整理的资料，检查是否准确，可以修改或划掉不合适的内容。确认后点击“确认，就是我”。AI 会依据这些资料生成页面，缺少的信息无需编造。

### ④ 生成并预览

点击“开始生成页面”，等待任务完成，然后点击“去预览第 … 版”。生成可能需要几分钟，请以任务状态为准。

建议观察：介绍是否忠于确认资料，页面是否表现出个人特点，以及在较窄窗口中是否仍便于阅读。生成得到的是可预览的页面版本，尚未自动发布。

### ⑤ 提出一次修改

在页面的修改区域选择想调整的区块，输入日常语言要求，例如：

> 把这部分的自我介绍改得轻松一点，保留前端和摄影两个特点，突出我想找设计师一起组队，不要新增经历。

点击“按这个修改”，完成后比较新旧版本。修改产生新版本，便于保留之前的结果。

### ⑥ 本人确认发布

返回创作工作区，选择通过校验的版本，在发布确认区域检查缩略卡和联系方式公开选项，再确认发布。返回黑客松人物墙，查看自己的卡片与页面。

**生成、修改与发布是分开的操作：最终由页面主人确认发布，AI 不会代替主人发布。**

## 6. 哪些是模拟数据，哪些是真实操作

| 项目 | 本次演示的实现方式 |
| --- | --- |
| 人物、头像、圈子背景、联系方式与历史聊天 | 虚构演示数据，不代表真实用户或真实社群活动 |
| 登录 | 两个预置身份创建实际本地会话，不发送真实邮件 |
| 已有个性页面 | 预置页面经过项目的提交、校验及渲染流程，用于直接浏览 |
| AI 采访、资料整理、页面生成与修改 | 调用真实模型，需要联网，不以固定结果冒充模型生成 |
| 消息、版本保存、预览与发布 | 由本地程序实际执行，结果保存在本机演示数据中 |
| 组织者权限 | 使用实际权限控制，组织者不能查看其他成员的草稿、版本和采访资料 |

网页内创作会将填写的资料发送至配置的模型服务，费用由演示提供者承担。建议使用上面的虚构素材。

本项目也支持使用自己的本地 AI Agent 创作：可在创作工作区按页面说明安装 NOWMe Skill，再生成一次性指令交给 Agent，提交页面后回到网页预览并确认发布。该路线需要额外准备本地 Agent，不是评委快速体验的前置条件。

## 7. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 找不到 `pnpm` | 确认已安装 Node.js，再运行第 2 节的 pnpm 安装命令；必要时重新打开终端 |
| 提示 `node:sqlite` 不可用或 Node 版本不符 | 使用 Node.js 22，至少 22.13.0，切换后重新安装依赖 |
| 提示 Chromium / 浏览器可执行文件不存在 | 在项目根目录运行 `pnpm exec playwright install chromium`；Linux 缺系统依赖时使用 `--with-deps` |
| 首次启动停留在字体下载 | 保持联网；失败后运行 `pnpm --filter @nowme/kit fonts:fetch`，成功后重新 `pnpm demo` |
| 提示 3000 或 4000 端口被占用 | 先关闭之前运行的 NOWMe；不要同时运行 `pnpm dev` 与 `pnpm demo`。需要修改端口时见第 9 节 |
| 打开首页失败 | 等待终端就绪提示，确认进程仍在运行，并使用 `http://localhost:3000`；如换过端口，使用终端实际打印的主站地址 |
| 人物页面空白 | 确认两个服务均已启动，后台 4000 端口没有被拦截；不要把主站地址改成 `127.0.0.1` |
| 没有一键体验入口 | 确认运行的是 `pnpm demo`，普通 `pnpm dev` 使用开发登录流程 |
| 提示“演示模型尚未配置” | 请提交者按第 9 节检查配置并重启；仍可浏览墙和已有页面 |
| AI 超时、限流或凭证错误 | 按页面提示重试；持续失败时请提交者检查模型额度、权限与网络。可先浏览已有页面，不需要评委购买模型额度 |
| 采访或工作区已有内容 | 重启会保留之前的体验结果；可继续操作，如需恢复初始状态，按第 8 节由维护者重建 |

## 8. 关闭、再次体验与恢复初始数据

- **关闭服务**：在运行 `pnpm demo` 的终端按 Ctrl+C，主站和页面服务会一起关闭。
- **再次体验**：在项目根目录重新执行 `pnpm demo`，已有页面、聊天和发布状态会保留。
- **数据位置**：演示数据保存在 `.data/demo`，与普通开发数据分开。

只有需要恢复初始场景时才重建。**以下命令会清空 `.data/demo` 中的本地演示数据，包含此次体验产生的采访、页面、消息和发布记录；如需保留，请先关闭服务并备份整个目录。**

```bash
pnpm demo --reset
```

重建后等待就绪提示，刷新浏览器并重新选择体验身份。不要为了普通重启而加 `--reset`。

## 9. 提交者维护说明

评委使用默认配置即可，本节供提交者准备与排查。正式评审前，建议在一份新下载的仓库中按第 2 节完成安装，实际验证一次“采访 → 生成 → 修改 → 发布”，并提前保留演示录屏。

### 模型配置

演示模型配置依次读取环境变量、`.env.local`、`.env`，最后读取仓库的 `.env.demo.shared`；前者优先。默认演示配置不可用时，参照根目录 [.env.demo.example](../.env.demo.example)，将需要的条目写入未跟踪的 `.env.local`，不要直接覆盖已有本地文件：

| 变量 | 用途 |
| --- | --- |
| `NOWME_AI_ENCRYPTION_KEY` | 64 位十六进制随机加密主密钥 |
| `NOWME_DEMO_PROVIDER` | 服务商标识，例如 `deepseek` 或 `openai-compatible` |
| `NOWME_DEMO_BASE_URL` | 公网 HTTPS API 根地址，不包含 `/chat/completions` |
| `NOWME_DEMO_MODEL` | 支持工具调用的模型名称 |
| `NOWME_DEMO_API_KEY` | 演示模型凭证 |
| `NOWME_DEMO_VISION` | `0` 或 `1`；模型不支持看图时使用 `0` |

可用 `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` 生成新的加密主密钥。已有数据应继续使用原主密钥，避免已有加密配置无法读取。

采访与生成默认共用上述配置。需要分开时，可用 `NOWME_DEMO_INTERVIEW_` 或 `NOWME_DEMO_GENERATE_` 前缀加 `PROVIDER`、`BASE_URL`、`MODEL`、`API_KEY`、`VISION` 覆盖相应角色。更换角色的服务商或地址时，同时提供该角色的 Key。

预置配置写入体验成员账号，账号模型表保存加密后的凭证。演示身份不能在网页中修改或删除预置模型。普通 `pnpm dev` 不读取演示模型变量，也不开放快捷登录。

演示模式禁止 `NOWME_MODEL_FAKE` / `NOWME_CLAUDE_FAKE`，不会在真实调用失败后自动切换为假模型。若代理返回 `198.18.*` 等保留地址，请检查 DNS；可通过 `NOWME_DEMO_DNS_SERVERS` 指定 DNS 服务器 IP（多个用逗号分隔）。程序仍检查公网地址并固定连接地址，不接受内网地址或重定向。

### 端口调整

保留主站 `localhost`、页面服务 `127.0.0.1` 两个不同主机名，以维持页面隔离。若默认端口被占用，需要在启动进程前设置环境变量（启动器会先设置默认端口，不能靠 `.env.local` 覆盖）。

macOS / Linux：

```bash
NOWME_WEB_ORIGIN=http://localhost:3400 NOWME_PAGES_ORIGIN=http://127.0.0.1:4400 pnpm demo
```

Windows PowerShell（在当前终端生效）：

```powershell
$env:NOWME_WEB_ORIGIN = "http://localhost:3400"
$env:NOWME_PAGES_ORIGIN = "http://127.0.0.1:4400"
pnpm demo
```

此时按终端提示打开 `http://localhost:3400`，本文中的默认 3000 地址相应替换。只改一侧的端口时，也应确保另一侧端口可用。
