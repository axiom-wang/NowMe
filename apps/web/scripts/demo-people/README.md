# 演示人物页（黑客松墙、摄影社墙）

这里的五个目录是演示种子用的人物页面，每个目录是一次提交的三个文件（`index.html`、`card.json`、`manifest.json`）。

- `hack-*`：NOWMe 演示黑客松墙上的程野、方棠、祝一一。
- `club-*`：山海摄影社墙上的贺川、麦冬。

页面是 2026-11-17 用产品自己的网页创作流程（采访 → 确认资料 → 生成）在隔离的演示数据上真实生成、原样保存的，没有手工改动；人物均为虚构。种子通过与其他示例页相同的提交管线（校验 + 渲染）把它们挂上墙，`demo-people-content.test.ts` 守住校验结果。

要换内容：在演示里用同样的流程重新生成一版，把该版本目录 `revisions/<rev_…>/original/` 下的三个文件覆盖进来。
