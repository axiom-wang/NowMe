归类后，三簇

我能帮你把访谈理成结论：八位受访者的话贴到墙上，按“他卡在哪一步”成簇。

A · 找不到入口

不知道社团在哪

信息散在各处

结论：新生需要一个按时间排好的入口，而不是一张长长的社团目录。

B · 怕第一次尴尬

怕没人认识

怕问错问题

想要一个见面理由

结论：第一次见面最好有一件具体的事可以一起做，话题会自己出来。

C · 想先试一下

先做一件小事

合不合再决定

结论：报名是大决定，体验一次才是新生愿意迈出的那一步。
