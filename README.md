# NOWMe

和 AI 一起，做一页有个性的自己，挂在圈子的共同墙上。

NOWMe 面向刚进入新圈子的年轻人，通过 AI 采访整理个人特点，生成可预览、可修改的个性页面，帮助成员发现共同兴趣、寻找队友、开启交流。

**华硕 A+ 青年 Create Lab 2026 · 本地演示原型**

## 评委体验入口

**[完整本地体验指南 →](docs/demo.md)**：包含启动步骤、测试身份、推荐体验路线、AI 创作说明与常见问题。

- 无需真实邮箱注册、密码或验证码，提供“成员”和“组织者”两个一键体验入口。
- 预置四面人物墙、个性页面及虚构聊天记录，可先浏览，再体验 AI 采访、生成、修改与本人确认发布。
- 当前版本在本地运行，没有公开网站地址；`localhost` 地址需要先在自己的电脑启动项目才能访问。

## 快速启动

准备 Git、Node.js 22（至少 22.13.0）和 pnpm 12.8.1，在终端执行：

```bash
git clone https://github.com/axiom-wang/NowMe.git
cd NowMe
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm demo
```

Linux 如提示缺少浏览器系统依赖，先运行 `pnpm exec playwright install --with-deps chromium`。

首次启动会下载缺失字体、渲染示例页面，请保持联网，等待终端提示“NOWMe 黑客松评审演示已就绪”。随后打开 **[本地体验首页](http://localhost:3000)**，选择“以成员身份体验”。不需要先构建，也不用另外启动页面服务。

仓库提供演示专用模型配置，评委无需填写自己的 API Key；AI 采访与生成需要联网，实际可用性取决于模型服务。详细体验步骤和配置排查见 [体验指南](docs/demo.md)。

## 推荐路线

- **约 3 分钟浏览**：成员登录 → 人物墙 → 个性页面 → 消息 → 切换组织者查看管理功能。
- **预留 10–15 分钟创作**：黑客松墙“继续创作” → 开始采访 → 确认资料 → 生成 → 预览和修改 → 本人确认发布。模型耗时可能更长。

人物、头像、联系方式和历史聊天为虚构演示数据；页面浏览、消息操作、权限管理及发布流程由本地程序实际执行。AI 创作调用真实模型，不以预制结果替代生成。

关闭服务：在运行终端按 Ctrl+C。再次执行 `pnpm demo` 会保留已有体验数据。
