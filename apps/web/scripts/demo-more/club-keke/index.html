问我 · ASK

我能教的一件事

怎么让被拍的人放松，可以来问我

  • 先聊十分钟不急着举相机，聊到对方不再盯着镜头，再开始拍。
  • 给一件小事做让对方剥橘子、看窗外、转头说句话，手和眼睛有去处，身体就松了。
  • 别喊“笑一下”喊了就是摆拍。我更愿意逗笑他，等那一下出来再按。
想试 · TRY

下一次的拍法

想试一次室内窗光人像

  • 找一扇朝北的窗，不要正午的直射光
  • 被拍的人坐在窗边，光从侧面来
  • 白纸或白墙做反光板，补一点阴影
