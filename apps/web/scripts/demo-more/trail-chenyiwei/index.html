可以来问我：怎么安排适合长辈的路线

路线不一定要远，要有能坐下来的地方、平缓的路段，还有一个能歇脚的站点。我带爸妈走过好几次，经验都记在本子里，你来问，我慢慢讲。

我也想试：三代人一起轻徒步

想试一次三代人的轻徒步，把走得最慢的那一位当作领路人，路上停得多，也看得多。

我在沉迷：在休息点泡一壶茶

随身带一个小茶罐和保温杯，到了休息点就停下来泡茶。茶凉得慢的时候，大家正好聊聊天。
